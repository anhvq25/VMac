# VMac

Tiện ích chăm sóc máy Mac (SwiftUI, macOS 26+): giám sát hệ thống, dọn dẹp, bóc tách "System Data", Xcode Deep Clean, quản lý ứng dụng — chạy cả trên menu bar.

## Tải về

👉 **[Tải bản mới nhất (VMac.dmg)](https://github.com/anhvq25/VMac/releases/latest)**

1. Mở file `.dmg`, kéo **VMac** vào **Applications**.
2. Mở VMac từ Launchpad / Applications.
3. Lần đầu: cấp **Full Disk Access** (System Settings › Privacy & Security › Full Disk Access) để VMac đọc được Thùng rác, backup iPhone và các thư mục hệ thống.

App được ký **Developer ID** (MONI TECHNOLOGY COMPANY LIMITED) và đã **notarize** với Apple — mở bình thường, không bị Gatekeeper chặn.

## Tính năng

- **Bảng điều khiển** — CPU theo core, RAM, ổ đĩa, pin, danh sách process (kill được).
- **Quét thông minh** — gom mọi thứ dọn được vào một chỗ.
- **Dữ liệu hệ thống** — bóc tách cục "System Data" trong Cài đặt › Dung lượng: simulator & runtime iOS, máy ảo Android, Docker, cache Gradle/uv/npm/pip…, dữ liệu app Electron (Cursor, VS Code, Slack), swap, snapshot Time Machine. Mỗi mục có mức an toàn và gợi ý xóa/giữ.
- **Xcode Deep Clean** — DerivedData theo project, Archives, DeviceSupport, simulator, provisioning hết hạn.
- **Dọn dẹp** — cache, log, Downloads cũ, node_modules, phân tích dung lượng.
- **Ảnh & Video**, **Ứng dụng** (gỡ sạch, login items, Homebrew), **Quyền riêng tư**, **Cài đặt nhanh**.

## Yêu cầu

macOS 26 trở lên · Apple Silicon hoặc Intel.
